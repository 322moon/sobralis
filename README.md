# Sobralis

Sobralis - приложение для поиска компании и организации совместных событий. Прогулка по городу, настольные игры дома, вечеринка, выезд на природу или путешествие - можно собрать людей под любые планы или присоединиться к чужим.

## Как это работает

- **Создай событие:** опиши идею, укажи место, время и количество участников.
- **Добавь условия:** бюджет, еду, транспорт, необходимые вещи и другие детали по желанию.
- **Собери компанию:** принимай заявки, обсуждай планы и распределяй подготовку.
- **Присоединяйся:** находи события по месту, времени и интересам.

Главная идея - помочь людям найти тех, с кем хочется провести время, и проще договориться о встрече. Формат свободный, а маршрут, транспорт и снаряжение нужны только там, где это актуально.

## Запуск

Требуется Docker с Docker Compose.

1. Создайте локальный файл настроек, если его ещё нет:

   ```bash
   cp -n .env.example .env
   ```

2. При первом запуске укажите свой пароль БД в `DB_PASSWORD` внутри `.env`. Существующий настроенный файл менять не нужно; он не попадает в Git.

3. Соберите и запустите проект:

   ```bash
   docker compose up --build -d
   ```

API доступен по адресу `http://localhost:8080/api/v1`.
